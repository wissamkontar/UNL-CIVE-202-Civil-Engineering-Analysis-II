Project 3

Transportation Data Visualization

Students use Python to create clear transportation visualizations and communicate patterns from national travel and driving behavior datasets.

Category Transportation Engineering
Focus Skill Visualize Data
Tools Python, Pandas, Matplotlib, Jupyter Notebook
01

Client Prompt

Client Prompt

The Federal Highway Administration is interested in understanding important trends in transportation usage and driving behavior. Your company has been provided with transportation datasets, including survey-based travel data and driving behavior data, along with metadata files that explain the available variables.

As the engineering intern with Python experience, students are asked to organize and visualize the data before a transportation planning meeting. The goal is to create clear, well-labeled plots that help engineers understand travel behavior, transportation trends, and vehicle movement patterns.

Client Requests

  1. Create a bar chart comparing categories within a transportation-related variable.
  2. Create a histogram showing the distribution of a selected variable.
  3. Create a boxplot showing how a variable is distributed across categories.
  4. Create at least two time-series plots that show and analyze driving behavior.
  5. Customize at least one plot beyond the default Python output using formatting, color, labels, or other visual design choices.
  6. Complete a simulation study using the Intelligent Driver Model to visualize vehicle behavior and trajectories.
  7. Document the time spent on each major analysis task using an engineering timesheet.

Deliverables and Requirements

Deliverables

  • A GitHub repository containing the code, data files, and a README file summarizing the project.
  • Data files used in the Python code file.
  • A Python Jupyter Notebook documenting the code used to generate all plots, simulations, and analysis outputs.
  • A scope of work identifying the variables selected for visualization and explaining how the NHTS or NGSIM metadata supports those choices.
  • A Gantt chart showing project tasks, dates, and responsibilities.
  • An engineering timesheet documenting time spent by each group member.
  • An annotated code document explaining each line or major block of code.
  • A written report summarizing the findings and explaining the relevance of the visualizations to transportation engineering.

Report Requirements

  • Introduction/background explaining the FHWA project and the analysis objectives.
  • Methods section describing the selected variables, why they were chosen, how each plot was constructed, and any simulation method used.
  • Results and discussion section explaining the key findings from each plot and how those findings could be relevant to the transportation industry.
  • Reference list and in-text citations for all datasets, metadata files, and other resources used.
