Project 5G

Drinking Water Access in Sub-Saharan Africa

Students analyze JMP WaSH data to compare drinking water access across countries and track how access has changed over time.

Category Infrastructure Analysis
Focus Skill Integrate Data Analysis Skills
Tools Python, Pandas, Visualization, JMP WaSH Data
01

Client Prompt

Client Prompt

The Water Project is a non-governmental organization working to improve drinking water service access around the world. In recent years, the organization has focused many of its efforts on Sub-Saharan Africa and wants to better understand how access has changed over time.

Students will examine JMP household drinking water access data to analyze trends across countries in Sub-Saharan Africa. The goal is to identify differences between countries, communicate changes in access over time, and explain what gaps may still need attention in the future.

Client Requests

  1. Analyze drinking water access data for countries in Sub-Saharan Africa.
  2. Create a summary table or figure comparing drinking water access across different countries.
  3. Create a time-series plot showing how drinking water access has changed over time.
  4. Compare patterns between countries and identify meaningful differences in access.
  5. Explain what the results suggest about remaining gaps in drinking water access.

Deliverables and Requirements

Deliverables

  • Cleaned and organized JMP drinking water access data files used in the Python analysis.
  • A Python notebook or code file documenting the full analysis workflow.
  • Python functions used to filter, summarize, group, or visualize the data.
  • At least two appropriate graphs or summary tables, including a country comparison and a time-series visualization.
  • A scope of work describing the analysis tasks completed for the client.
  • A Gantt chart showing project tasks, responsibilities, dates, and task bars.
  • A timesheet documenting hours spent on each major project activity.
  • Technical and non-technical executive summaries.
  • A written report summarizing findings and infrastructure access insights.

Report Requirements

  • A discussion of differences in drinking water access among countries in Sub-Saharan Africa.
  • A clear explanation of what each table or plot shows.
  • A discussion of changes in drinking water access over time.
  • An interpretation of which countries or regions may still have the greatest access gaps.
  • A methods section explaining how the JMP data were selected, cleaned, filtered, grouped, and visualized.
  • References and citations for all datasets, documentation, and supporting research used in the report.
