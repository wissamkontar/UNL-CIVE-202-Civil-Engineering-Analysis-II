Project 4

Infrastructure Access & Bias

Students use FEMA National Risk Index data to examine how definitions, assumptions, and coding decisions can shape engineering conclusions about natural hazard risk.

Category Infrastructure Analysis
Focus Skill Interpret Data & Bias
Tools Python, Pandas, GeoPandas, Jupyter Notebook
01

Client Prompt

Client Prompt

Risk Averse, LLC has hired your team to investigate how natural hazard risk is defined, scored, and interpreted using FEMA National Risk Index data. The client wants to understand whether different definitions of risk can lead to different conclusions about which communities appear most vulnerable.

Students will compare the original National Risk Index scoring approach with an alternative risk definition developed by their team. The goal is to determine whether categorical bias may exist in how risk is measured, classified, and communicated to decision-makers.

Client Requests

  1. Download, clean, and organize National Risk Index data for two selected states at the Census Tract level.
  2. Use NRI metadata files to understand and clarify important variables in the dataset.
  3. Use Social Vulnerability Index data as part of the analysis.
  4. Join multiple datasets together to support future analysis for the client.
  5. Handle missing or unavailable values appropriately in the dataset.
  6. Generate summary tables or figures comparing risk scoring under both the NRI definition and the team’s proposed definition.
  7. Create at least one GeoPandas map that communicates risk information to the client.

Deliverables and Requirements

Deliverables

  • Raw and cleaned data files used in the Python code file.
  • A Python code file documenting the analysis used to generate the final results.
  • An annotated code document explaining each line or major block of code.
  • A scope of work defining the tasks completed for Risk Averse, LLC.
  • A Gantt chart showing project tasks, responsibilities, and schedule.
  • A timesheet documenting hours spent on each activity and by whom.
  • A GitHub repository link containing all code and project data files.
  • A written report summarizing the risk analysis findings for the client.

Report Requirements

  • A clear methodology explaining how the team defined risk so the analysis can be reproduced.
  • A written comparison of the team’s proposed risk definition with the original National Risk Index definition.
  • Discussion of ethical implications, including possible bias in risk definitions, funding implications, data collection concerns, and how communities may interpret the results.
  • A written comparison of results generated using both the NRI risk definition and the proposed risk definition.
  • Discussion of how differences in risk scoring may affect communities impacted by natural disasters and future mitigation funding decisions.
