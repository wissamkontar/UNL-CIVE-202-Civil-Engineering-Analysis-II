Project 1

Air Quality Data

Students use Python to organize, summarize, and interpret Nebraska air-quality sensor data for a public-health-focused client.

Category Environmental Engineering
Focus Skill Organize & Summarize Data
Tools Python, Pandas, Jupyter Notebook
01

Client Prompt

Client Prompt

The UNMC Water, Climate and Health Group works on issues related to how water, air, and soil pollution can negatively affect human health. UNMC recently started an initiative with AirPurple to monitor air-quality conditions across Nebraska. Because air quality is not the specialty of the current UNMC working group, the group opened a request for proposals from engineering firms and independent consultants to analyze the AirPurple monitor dataset from February 2024 to March 2025.

Your engineering firm has been awarded the project and is responsible for completing the requested air-quality analysis. The final work should help UNMC understand potential air-quality conditions in Nebraska, whether air quality is meeting National Ambient Air Quality Standards, and where potential public-health “hotspots” may exist.

Client

UNMC Water, Climate and Health Group

Client Requests

  1. Identify the 5 locations in Nebraska with the highest mean and median concentrations of VOC, PM 2.5, and PM 10.0.
  2. Determine on what days the maximum values occurred and where those maximums occurred. Students should also conduct initial research to explain possible reasons for those maximum values.
  3. Analyze whether humidity and temperature have a noticeable effect on air quality. Humidity should be grouped as low, high, and very high. Temperature should be grouped as below freezing, cool, warm, and hot.
  4. Determine whether any Air Quality Index health risks occurred for PM 2.5 and PM 10.0 based on EPA AQI ratings. Students should identify when they happened and research possible causes.
  5. Bonus: Analyze whether sensor altitude has an impact on air-quality values.

Resources Provided by the Client

  • AirPurple Map
  • Purple Air Community
  • EPA Air Quality Index Document
  • AirNow website

Deliverables

  • Raw data files used in the Python code file.
  • A Python code file documenting the analysis. This must be submitted as a Jupyter Notebook file.
  • A GitHub link containing the Python code, CSV data, and a README file.
  • A well-written scope of work defining the tasks completed by the group.
  • An annotated code document explaining each line of code in detail.
  • A written report summarizing the findings and meeting the client’s requested analysis.

Report Requirements

  • Introduction/background explaining the project, scope of work, and objectives.
  • Methods section explaining how the data analysis was completed. The methods should be detailed enough that another analyst could reproduce the analysis.
  • Results and discussion section presenting the analysis results and explaining observations or possible reasons for those observations.
  • Reference list and in-text citations for all resources used.

Starter Code

Starter Code

This starter code gives students a structured beginning for loading the AirPurple dataset, creating humidity and temperature categories, grouping by sensor name, summarizing pollutant values, identifying AQI concern events, and exploring the optional altitude question. 

import pandas as pd

# ------------------------------------------------------------
# Step 1: Load and inspect the air-quality dataset
# ------------------------------------------------------------

air_data = pd.read_csv("AirQuality_Daily_StudentVersion.csv")

# Convert to a dataframe. This is optional because read_csv already
# returns a dataframe, but it makes the structure explicit.
air_data = pd.DataFrame(air_data)

# Preview the dataset
air_data.head()

# Check available columns
air_data.columns
# ------------------------------------------------------------
# Step 2: Create humidity and temperature categories
# ------------------------------------------------------------

def assign_humidity(humidity):
    if humidity < 50:
        return "Low"
    elif 50 <= humidity <= 80:
        return "High"
    else:
        return "Very High"


def assign_temperature(temperature):
    if temperature < 32:
        return "Below Freezing"
    elif 32 <= temperature <= 50:
        return "Cool"
    elif 51 <= temperature <= 70:
        return "Warm"
    else:
        return "Hot"


air_data["humidity_level"] = air_data["humidity"].apply(assign_humidity)
air_data["temperature_level"] = air_data["temperature"].apply(assign_temperature)

air_data[["humidity", "humidity_level", "temperature", "temperature_level"]].head()
# ------------------------------------------------------------
# Step 3: Group data by sensor name
# ------------------------------------------------------------

air_data_grouped = air_data.groupby("sensor.name")

# Summary statistics for PM 2.5
pm25_summary = air_data_grouped.agg(
    max_pm25=("pm2.5_atm", "max"),
    min_pm25=("pm2.5_atm", "min"),
    mean_pm25=("pm2.5_atm", "mean"),
    median_pm25=("pm2.5_atm", "median")
).round(2)

pm25_summary.head()
# ------------------------------------------------------------
# Step 4: Summarize PM 10.0 and VOC values by sensor
# ------------------------------------------------------------

pm10_summary = air_data_grouped.agg(
    max_pm10=("pm10.0_atm", "max"),
    min_pm10=("pm10.0_atm", "min"),
    mean_pm10=("pm10.0_atm", "mean"),
    median_pm10=("pm10.0_atm", "median")
).round(2)

voc_summary = air_data_grouped.agg(
    max_voc=("voc", "max"),
    min_voc=("voc", "min"),
    mean_voc=("voc", "mean"),
    median_voc=("voc", "median")
).round(2)

pm10_summary.head()
voc_summary.head()
# ------------------------------------------------------------
# Step 5: Find the top 5 sensor locations by mean and median
# ------------------------------------------------------------

top5_mean_pm25 = pm25_summary.sort_values(
    by="mean_pm25",
    ascending=False
).head(5)

top5_median_pm25 = pm25_summary.sort_values(
    by="median_pm25",
    ascending=False
).head(5)

top5_mean_pm25
top5_median_pm25
# ------------------------------------------------------------
# Step 6: Analyze humidity effects on air quality
# ------------------------------------------------------------

humidity_grouped = air_data.groupby("humidity_level")

humidity_pm25_summary = humidity_grouped.agg(
    max_pm25=("pm2.5_atm", "max"),
    min_pm25=("pm2.5_atm", "min"),
    mean_pm25=("pm2.5_atm", "mean"),
    median_pm25=("pm2.5_atm", "median")
).round(2)

humidity_pm10_summary = humidity_grouped.agg(
    max_pm10=("pm10.0_atm", "max"),
    min_pm10=("pm10.0_atm", "min"),
    mean_pm10=("pm10.0_atm", "mean"),
    median_pm10=("pm10.0_atm", "median")
).round(2)

humidity_voc_summary = humidity_grouped.agg(
    max_voc=("voc", "max"),
    min_voc=("voc", "min"),
    mean_voc=("voc", "mean"),
    median_voc=("voc", "median")
).round(2)

humidity_pm25_summary
# ------------------------------------------------------------
# Step 7: Analyze temperature effects on air quality
# ------------------------------------------------------------

temperature_grouped = air_data.groupby("temperature_level")

temperature_pm25_summary = temperature_grouped.agg(
    max_pm25=("pm2.5_atm", "max"),
    min_pm25=("pm2.5_atm", "min"),
    mean_pm25=("pm2.5_atm", "mean"),
    median_pm25=("pm2.5_atm", "median")
).round(2)

temperature_pm25_summary
# ------------------------------------------------------------
# Step 8: Identify AQI concern events
# ------------------------------------------------------------
# PM 2.5 becomes unhealthy for sensitive groups at 35.5 µg/m³.
# PM 10.0 becomes unhealthy for sensitive groups at 155 µg/m³.

air_data["pm2.5_atm"] = pd.to_numeric(air_data["pm2.5_atm"], errors="coerce")
air_data["pm10.0_atm"] = pd.to_numeric(air_data["pm10.0_atm"], errors="coerce")

unhealthy_pm25 = air_data[air_data["pm2.5_atm"] >= 35.5]
unhealthy_pm10 = air_data[air_data["pm10.0_atm"] >= 155]

unhealthy_pm25_events = unhealthy_pm25[
    ["date", "sensor.name", "pm2.5_atm"]
].sort_values("date")

unhealthy_pm10_events = unhealthy_pm10[
    ["date", "sensor.name", "pm10.0_atm"]
].sort_values("date")

unhealthy_pm25_events.head(10)
# ------------------------------------------------------------
# Step 9: Create a summary table for AQI concern events
# ------------------------------------------------------------

pm25_aqi_summary = pd.pivot_table(
    unhealthy_pm25,
    index="sensor.name",
    values="pm2.5_atm",
    aggfunc=["count", "mean", "max"]
).round(2)

pm25_aqi_summary
# ------------------------------------------------------------
# Optional Bonus: Explore whether altitude relates to air quality
# ------------------------------------------------------------
# This is a more advanced analysis. Students should explain
# any code used here in the annotated code document.

import matplotlib.pyplot as plt
from scipy.stats import pearsonr, spearmanr

altitude_voc_data = air_data[["sensor.altitude", "voc"]].dropna()

plt.scatter(altitude_voc_data["sensor.altitude"], altitude_voc_data["voc"])
plt.xlabel("Sensor Altitude")
plt.ylabel("VOC Concentration")
plt.title("VOC Concentration vs. Sensor Altitude")
plt.show()

pearson_r, pearson_p = pearsonr(
    altitude_voc_data["sensor.altitude"],
    altitude_voc_data["voc"]
)

spearman_r, spearman_p = spearmanr(
    altitude_voc_data["sensor.altitude"],
    altitude_voc_data["voc"]
)

print(f"Pearson correlation coefficient: {pearson_r:.3f}")
print(f"Pearson p-value: {pearson_p:.3e}")
print(f"Spearman correlation coefficient: {spearman_r:.3f}")
print(f"Spearman p-value: {spearman_p:.3e}")
