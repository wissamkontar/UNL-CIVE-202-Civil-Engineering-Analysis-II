Project 2

Automation of Concrete Mix Design

Students translate an Excel-based NDOT concrete mix design workflow into a Python program using functions, user inputs, and scenario testing.

Category Structural Engineering
Focus Skill Automate Engineering Calculations
Tools Python, Functions, Jupyter Notebook, GitHub
01

Client Prompt

Client Prompt

The Nebraska Department of Transportation has contracted your firm to migrate an existing concrete mix design workflow from Excel into Python. The goal is to recreate the logic from the NDOT mix design spreadsheet so that engineers can enter material properties and design parameters in a structured, repeatable way.

Students will build a Python-based tool that automates key mix design calculations, collects user inputs step by step, and produces a final weight chart for one cubic yard of concrete. The project helps students practice turning spreadsheet-based engineering logic into transparent, reusable code.

Client Requests

  1. Translate the calculations from the NDOT concrete mix design spreadsheet into Python functions.
  2. Create sequential user inputs so an engineer can enter required design values in a logical order.
  3. Generate a final concrete mix design output with clearly labeled material weights for one cubic yard of concrete.
  4. Research and evaluate four realistic concrete mix scenarios using the automated Python workflow.

Deliverables and Requirements

Deliverables

  • A GitHub repository containing the code, data files, and a README file explaining how to use the program.
  • A Python Jupyter Notebook documenting the automation logic, user input prompts, and four mix design scenario runs.
  • Four researched concrete mix design scenarios that can be evaluated using the automated model.
  • A well-written scope of work defining the tasks completed to automate the NDOT concrete mix design workflow.
  • A Gantt chart showing project tasks, responsibilities, dates, and task bars.
  • An annotated code document explaining how the Excel formulas were translated into Python functions.
  • A technical report summarizing the implementation, scenario results, and engineering interpretation.

Report Requirements

  • Introduction/background explaining the NDOT project and the objective of automating the concrete mix design workflow.
  • Methods section explaining how the Excel calculations were translated into Python, including key input and output parameters.
  • Results and discussion section comparing the four concrete mix scenarios and explaining the differences in the generated outputs.
  • Reference list and in-text citations for NDOT documents and any other engineering references used.
