Project 2

Automation of Concrete Mix Design

Students translate an Excel-based NDOT concrete mix design workflow into a transparent, repeatable Python program using functions, user inputs, and scenario testing.

Category Structural / Geotechnical Engineering
Focus Skill Automate Engineering Calculations
Tools Python, Functions, Jupyter Notebook, GitHub
01

Client Prompt

Client Prompt

The Nebraska Department of Transportation has contracted your firm to migrate its existing concrete mix design model from an Excel-based workflow to a Python-based system. The primary goal is to replicate and automate the logic contained in the NDOT Mix Design worksheet so users can enter material properties and design parameters step by step.

The final program should generate a clear weight chart for one cubic yard of concrete. Beyond simple replication, this project improves the reliability of the mix design process by moving calculations from an offline spreadsheet to a transparent, repeatable Python workflow that could later be integrated into a web-based tool.

Client

Nebraska Department of Transportation (NDOT)

Client Requests

  1. Translate the Excel logic into Python. Replicate the calculations found in the Mix Design worksheet. Each major calculation should be implemented as a clearly defined Python function.
  2. Implement sequential user inputs. The program should prompt users to enter required design inputs step by step, including cement content, water–cement ratio, air content, aggregate proportions, and specific gravities.
  3. Generate a final mix design output. The program should produce a clearly formatted weight chart for one cubic yard of concrete. Output values should be labeled and presented in a professional, client-readable format.
  4. Prepare and evaluate four concrete mix scenarios. Students must research four realistic concrete mix scenarios and evaluate each one using the automated Python workflow as a basic form of verification and validation.

Resources Provided by the Client

  • NDOT Concrete Mix Excel workbook.
  • NDOT report on optimized aggregate gradations for concrete mix design.
  • NDOT Standard Specifications for Highway Construction.

Deliverables

  • GitHub repository containing code, data, and a README file with a user guide for the sequential input prompts.
  • Scope of Work defining the tasks completed to automate the NDOT model.
  • Gantt chart showing project tasks, responsibilities, dates, and task bars.
  • Four researched concrete mix design scenarios evaluated using the Python model.
  • Jupyter Notebook documenting the automation logic, sequential prompts, and four scenario runs.
  • Annotated Code Document explaining how the Excel formulas were converted into Python functions.
  • Technical report with introduction, methods, results/discussion, and references.

Skills Students Will Practice

  • Creating interactive Python scripts using sequential input prompts.
  • Translating engineering formulas from Excel into Python functions.
  • Using Gantt charts to manage project timelines and dependencies.
  • Managing professional code repositories with GitHub and README documentation.
  • Writing a Scope of Work and technical report for an engineering client.
  • Creating annotated code for transparency and accountability.
  • Applying NDOT specifications to a data-driven engineering workflow.

Starter Code

Starter Code

This starter code helps students translate the NDOT mix design worksheet into Python. It introduces constants, calculation functions, sequential user inputs, and a final client-readable weight chart. 

# Project #2: Automation of Concrete Mix Design
# Client: Nebraska Department of Transportation (NDOT)

project_name = "Project #2: Automation of NDOT Concrete Mix Design"
client = "Nebraska Department of Transportation (NDOT)"

print(project_name)
print(f"Client: {client}")
# ------------------------------------------------------------
# Step 1: Define constants
# ------------------------------------------------------------

CUBIC_YARD_FT3 = 27        # cubic feet in one cubic yard
UNIT_WEIGHT_WATER = 62.4   # lb/ft^3

print(f"1 cubic yard = {CUBIC_YARD_FT3} cubic feet")
print(f"Unit weight of water = {UNIT_WEIGHT_WATER} lb/ft^3")
# ------------------------------------------------------------
# Step 2: Calculate water weight
# ------------------------------------------------------------
# Q = (A + B + C + D) * E
#
# A = cement weight
# B = fly ash weight
# C = silica fume weight
# D = other SCM weight
# E = target water-cement ratio

def calculate_water_weight_Q(cement_A, fly_ash_B, silica_fume_C, other_scm_D, wc_ratio_E):
    total_cementitious = cement_A + fly_ash_B + silica_fume_C + other_scm_D
    water_weight_Q = total_cementitious * wc_ratio_E
    return water_weight_Q
# ------------------------------------------------------------
# Step 3: Calculate cementitious material volumes
# ------------------------------------------------------------
# General formula:
# Volume = Weight / (Specific Gravity * Unit Weight of Water)

def calculate_volume_R(cement_A, sg_cement_J):
    volume_R = cement_A / (sg_cement_J * UNIT_WEIGHT_WATER)
    return volume_R


def calculate_volume_S(fly_ash_B, sg_fly_ash_K):
    volume_S = fly_ash_B / (sg_fly_ash_K * UNIT_WEIGHT_WATER)
    return volume_S


def calculate_volume_T(silica_fume_C, sg_silica_fume_L):
    volume_T = silica_fume_C / (sg_silica_fume_L * UNIT_WEIGHT_WATER)
    return volume_T


def calculate_volume_U(other_scm_D, sg_other_scm_M):
    volume_U = other_scm_D / (sg_other_scm_M * UNIT_WEIGHT_WATER)
    return volume_U
# ------------------------------------------------------------
# Step 4: Calculate air and water volumes
# ------------------------------------------------------------

def calculate_air_volume_V(air_content_F):
    volume_V = (air_content_F / 100) * CUBIC_YARD_FT3
    return volume_V


def calculate_water_volume_W(water_weight_Q):
    volume_W = water_weight_Q / UNIT_WEIGHT_WATER
    return volume_W
# ------------------------------------------------------------
# Step 5: Calculate total aggregate volume
# ------------------------------------------------------------
# X = 27 - R - S - T - U - V - W

def calculate_total_aggregate_volume_X(volume_R, volume_S, volume_T, volume_U, volume_V, volume_W):
    volume_X = CUBIC_YARD_FT3 - volume_R - volume_S - volume_T - volume_U - volume_V - volume_W
    return volume_X
# ------------------------------------------------------------
# Step 6: Calculate aggregate weights
# ------------------------------------------------------------
# Y  = fine aggregate weight
# Z  = coarse aggregate weight
# AA = other aggregate weight

def calculate_fine_aggregate_Y(percent_fine_G, sg_fine_N, volume_X):
    weight_Y = UNIT_WEIGHT_WATER * (percent_fine_G / 100) * sg_fine_N * volume_X
    return weight_Y


def calculate_coarse_aggregate_Z(percent_coarse_H, sg_coarse_O, volume_X):
    weight_Z = UNIT_WEIGHT_WATER * (percent_coarse_H / 100) * sg_coarse_O * volume_X
    return weight_Z


def calculate_other_aggregate_AA(percent_other_I, sg_other_P, volume_X):
    weight_AA = UNIT_WEIGHT_WATER * (percent_other_I / 100) * sg_other_P * volume_X
    return weight_AA
# ------------------------------------------------------------
# Step 7: Collect sequential user inputs
# ------------------------------------------------------------
# These prompts mirror the idea of moving through the Excel worksheet
# in a controlled, step-by-step order.

project_number = int(input("Enter project number: "))
class_of_concrete = input("Enter class of concrete, such as 47B or 47BR: ")

# Cementitious material inputs
cement_A = float(input("Enter cement weight A (lb per cubic yard): "))
fly_ash_B = float(input("Enter fly ash weight B (lb per cubic yard): "))
silica_fume_C = float(input("Enter silica fume weight C (lb per cubic yard): "))
other_scm_D = float(input("Enter other SCM weight D (lb per cubic yard): "))

# Design parameters
water_cement_ratio_E = float(input("Enter target water-cement ratio E: "))
air_content_F = float(input("Enter target air content F (%): "))

# Aggregate proportions
percent_fine_G = float(input("Enter percent fine aggregate G (%): "))
percent_coarse_H = float(input("Enter percent coarse aggregate H (%): "))
percent_other_I = float(input("Enter percent other aggregate I (%): "))

# Specific gravities
sg_cement_J = float(input("Enter specific gravity of cement J: "))
sg_fly_ash_K = float(input("Enter specific gravity of fly ash K: "))
sg_silica_fume_L = float(input("Enter specific gravity of silica fume L: "))
sg_other_scm_M = float(input("Enter specific gravity of other SCM M: "))

sg_fine_N = float(input("Enter specific gravity of fine aggregate N: "))
sg_coarse_O = float(input("Enter specific gravity of coarse aggregate O: "))
sg_other_P = float(input("Enter specific gravity of other aggregate P: "))

print("\nAll user inputs collected successfully.")
# ------------------------------------------------------------
# Step 8: Run the complete mix design calculation
# ------------------------------------------------------------

Q = calculate_water_weight_Q(
    cement_A,
    fly_ash_B,
    silica_fume_C,
    other_scm_D,
    water_cement_ratio_E
)

R = calculate_volume_R(cement_A, sg_cement_J)
S = calculate_volume_S(fly_ash_B, sg_fly_ash_K)
T = calculate_volume_T(silica_fume_C, sg_silica_fume_L)
U = calculate_volume_U(other_scm_D, sg_other_scm_M)

V = calculate_air_volume_V(air_content_F)
W = calculate_water_volume_W(Q)

X = calculate_total_aggregate_volume_X(R, S, T, U, V, W)

Y = calculate_fine_aggregate_Y(percent_fine_G, sg_fine_N, X)
Z = calculate_coarse_aggregate_Z(percent_coarse_H, sg_coarse_O, X)
AA = calculate_other_aggregate_AA(percent_other_I, sg_other_P, X)
# ------------------------------------------------------------
# Step 9: Print final client-readable weight chart
# ------------------------------------------------------------

print("\n---------------------------------------------")
print(" NDOT Concrete Mix Design - Weight Summary")
print("         1 Cubic Yard of Concrete")
print("---------------------------------------------")

print(f"Project Number:       {project_number}")
print(f"Class of Concrete:    {class_of_concrete}")

print(f"Other SCM (D):         {other_scm_D:8.1f} lb")

print("---------------------------------------------")
print("Aggregates")
