Project 5D

Balanced Mix Design Automation

Students automate NDOT asphalt mix design workflows using raw performance test data, engineering calculations, plots, and pass/fail decision metrics.

Category Geotechnical Engineering
Focus Skill Integrate Data Analysis Skills
Tools Python, Pandas, Functions, Visualization
01

Client Prompt

Client Prompt

The Nebraska Department of Transportation is transitioning its asphalt mixture approval process to a Balanced Mix Design framework. This approach requires engineers to analyze raw performance test data for cracking and rutting instead of relying only on simple volumetric measurements.

NDOT currently uses a spreadsheet-based workflow that requires manual copy-pasting and calculations. Students are asked to develop a Python-based automation tool that can process raw input data, calculate engineering decision metrics, generate plots, and produce repeatable outputs for future asphalt mix design evaluations.

Client Requests

  1. Create an aggregate gradation module that reads sieve data and blend ratios, plots the combined gradation curve, and compares results to NDOT control points.
  2. Create a volumetric properties calculator that reads measurements, applies the required equations, and flags invalid samples based on air void criteria.
  3. Create an IDEAL-CT module that analyzes load-displacement data and calculates the CT index from cracking performance test results.
  4. Create a Hamburg Wheel Tracking Test module that analyzes rut depth over cycles, identifies the stripping inflection point, and determines pass/fail performance.
  5. Generate clean plots and summary outputs that can be used in an engineering report.

Deliverables and Requirements

Deliverables

  • A fully functional Python notebook or code file that runs the balanced mix design automation workflow.
  • A module for aggregate gradation analysis with a combined gradation plot.
  • A module for volumetric property calculations and air void validity checks.
  • A module for IDEAL-CT analysis with load-displacement plots and CT index values.
  • A module for Hamburg Wheel Tracking Test analysis with rut depth plots, stripping inflection point detection, and pass/fail output.
  • A user guide explaining how an NDOT engineer should format input data for the tool.
  • A scope of work describing the automation tasks completed for the client.
  • A Gantt chart showing project tasks, responsibilities, dates, and task bars.
  • A timesheet documenting hours spent on each major project activity.
  • Technical and non-technical executive summaries.
  • A written report summarizing the automated workflow, results, and engineering decisions.

Report Requirements

  • A clear explanation of how the spreadsheet workflow was translated into Python modules.
  • A description of the input data needed for each module and how the code processes it.
  • Plots showing combined gradation, load versus displacement, and rut depth versus cycles.
  • A discussion of how validity checks, CT index calculations, stripping inflection point detection, and pass/fail decisions were implemented.
  • A user-focused explanation of how an NDOT engineer could run or adapt the tool.
  • References and citations for all NDOT documents, formulas, and supporting resources used.
