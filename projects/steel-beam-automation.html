Project 5C

Steel Beam Calculation Automation

Students build Python functions to automate AISC steel tension member calculations and compare design results across multiple engineering scenarios.

Category Structural Engineering
Focus Skill Integrate Data Analysis Skills
Tools Python, Functions, Visualization, AISC References
01

Client Prompt

Client Prompt

Kiewit Corporation has a structural engineering team that regularly uses the American Institute of Steel Construction manual to perform building design calculations. Many engineers have built their own spreadsheets to complete these calculations, but those tools are not always shared, standardized, or consistent across the office.

The Structural PE Program Manager has asked your team to create a proof-of-concept Python program that can automate calculations for a W-shaped tension member. Students will create reusable functions, run several design scenarios, and visualize how the results change across different input conditions.

Client Requests

  1. Create Python functions that automate calculations for a W-shaped steel tension member.
  2. Use the AISC manual and example documents as the basis for the automated calculations.
  3. Run three different sets of input variables through the automated design functions.
  4. Plot the results from the design scenarios to compare how inputs affect the final outputs.
  5. Explain how the automated function can be used by future engineers in the firm.

Deliverables and Requirements

Deliverables

  • A Python notebook or code file containing reusable functions for steel tension member calculations.
  • Three design scenarios tested using the automated Python functions.
  • At least two appropriate graphs or tables comparing results across the design scenarios.
  • Clean documentation of the function inputs, calculations, and outputs.
  • A scope of work describing the automation task completed for the client.
  • A Gantt chart showing project tasks, responsibilities, dates, and task bars.
  • A timesheet documenting hours spent on each major project activity.
  • Technical and non-technical executive summaries.
  • A written report explaining the automation process and how future engineers can use the tool.

Report Requirements

  • An explanation of the Python functions created for the required steel design calculations.
  • A clear list of function inputs, outputs, and assumptions.
  • A discussion of how the AISC calculations were translated into Python logic.
  • Tables or plots comparing results across the three design scenarios.
  • A user-focused explanation of how future employees could use or modify the function.
  • References and citations for all AISC documents and supporting design resources used.
